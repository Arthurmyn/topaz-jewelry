# Topaz Jewelry: структура сайта

Основа: референсы goldberry.shop и pandora.kz (страницы прочитаны, детали ниже) и архитектура из `ARCHITECTURE.md`.
**bulgari.com не удалось открыть (403)**, поэтому раздел про люксовые паттерны помечен как предположение, а не наблюдение.

Приоритеты: **P0** = MVP (14 дней), **P1** = сразу после запуска, **P2** = позже.
Метки модулей: `[accounts]` и `[payments]` показываются только при включённых флагах.

## 1. Что взято из референсов

| Источник | Что берём | Что не берём |
|----------|-----------|--------------|
| **Goldberry** (ювелирка РК, золото 585/750, как у нас) | Каталог по типам украшений; фильтры по золоту (цвет), пробе, камням, цене; цена «от X ₸»; блок «Характеристики» с таблицей (проба, вес, вставки, размер); вкладки доставка/гарантия/рассрочка; услуги (индивидуальное изготовление, ремонт, оценка); подарочные карты; кнопка WhatsApp, закреплённая на мобильном; блок «Почему нас выбирают» | 40 значений фильтра «Стиль», огранка/чистота/цвет бриллиантов (нет в нашей схеме, избыточно для MVP); каждая страница с 43 страницами пагинации без SEO-текста |
| **Pandora KZ** (сильный e-commerce) | Мега-меню с подкатегориями; сортировка (новизна, цена, популярность, скидка); выбор размера на карточке со ссылкой «Как определить размер?»; «Уведомить о поступлении»; «Наличие в магазинах»; сворачиваемые блоки «Оплата / Доставка / Упаковка»; подборки по поводу («Для мамы», «Свадьба», «До 30 000 ₸»); страница размеров, уход за украшениями, FAQ; блок «Найти магазин»; SEO-текст внизу категории | Шармы, коллаборации, outlet, бонусный клуб, мобильное приложение (не наш масштаб); бесконечный скролл (оставляем простую пагинацию для SEO) |
| **Bulgari** (предположение, не проверено) | Редакционный тон, крупная фотография, минимум шума, раздел «Услуги» (запись в салон, подарочная упаковка), история бренда | всё остальное |

Главный вывод для Topaz: премиальный минимализм Bulgari в визуале, функциональность Goldberry в каталоге, сервисные страницы Pandora.

## 3. Навигация

**Шапка (десктоп):** логотип по центру/слева · Каталог · Салоны · О нас · Доставка и оплата · Контакты · иконки: поиск, избранное `[accounts]`, профиль `[accounts]`, корзина.

**Мега-меню «Каталог»** (как у Pandora, но компактнее):
- Колонка 1: Кольца → Помолвочные, Обручальные, Женские, Мужские
- Колонка 2: Серьги → Пусеты, С бриллиантами, Подвесные
- Колонка 3: Подвески, Колье, Браслеты, Цепи
- Колонка 4 «Подборки»: Новинки, Для неё, Для него, Свадьба, Подарки до N ₸
- Справа: одно крупное фото-промо (управляется баннером из админки)

Подкатегории в MVP закладываем через `categories.parent_id`; сейчас в seed есть только «Обручальные кольца», остальные добавляются в админке без разработки.

**Мобильная версия:** бургер-меню с аккордеоном категорий; нижняя панель (как у Goldberry): Главная · Каталог · Корзина · Профиль `[accounts]` · Чат (WhatsApp).

**Футер (4 колонки, по образцу Pandora):**
1. **Каталог:** категории
2. **Покупателям:** Доставка и оплата, Гарантия и возврат, Как определить размер, Уход, FAQ
3. **О компании:** О нас, Салоны, Контакты, Блог (P2)
4. **Связь:** телефоны, WhatsApp, Instagram, график работы; форма подписки на рассылку
Нижняя строка: оферта, политика конфиденциальности, реквизиты.

## 4. Шаблоны страниц

### 4.1 Главная (P0)
Порядок блоков (смесь Goldberry и Pandora):
1. Лента-анонс (опционально, из `banners`): доставка по Казахстану, рассрочка, если будет
2. Hero-баннер(ы), 1-3 слайда из админки
3. Категории: плитки с фото (Кольца, Серьги, Подвески, Браслеты, Цепи)
4. Новинки: 8 товаров из каталога
5. Подборки по поводу (3-4 плитки): «Помолвка», «Подарок до 100 000 ₸» и т.п. (P1)
6. «Почему Topaz»: золото 585 и 750, проверка пробирной палатой, ограниченные серии, гарантия
7. Услуги: изготовление, ремонт, оценка (P1, если клиент их предоставляет)
8. Салоны: Астана и Караганда, адрес, часы, кнопка «Построить маршрут»
9. Подписка на рассылку (двойное подтверждение)

### 4.2 Каталог / категория (P0)
- Хлебные крошки, заголовок, число товаров
- **Фильтры** (левая колонка на десктопе, шторка на мобильном), всё в URL:

| Фильтр | Реализация сейчас | Заметка |
|--------|-------------------|---------|
| Категория | да | |
| Металл, цвет золота | металл есть; **цвет золота есть в данных (`gold_color`), но в фильтре его пока нет** | добавить в P0 (у Goldberry это ключевой фильтр) |
| Проба 585/750 | да | |
| Вставки (камни) | да | |
| Цена от/до | да | |
| Наличие | да | |
| Размер | нет | добавить P1 (по `product_variants.size`) |
| Вес, форма огранки, чистота/цвет бриллиантов | нет | P2, только если клиент даёт данные |
| Стиль | нет | не берём |

- Сортировка: новинки, цена вверх, цена вниз (P0); популярность, скидка (P1)
- Карточка: фото, название, «от X ₸», бейджи (проба, «Новинка», «Нет в наличии»), избранное `[accounts]` (P1)
- Пагинация (не бесконечная прокрутка: лучше для SEO)
- Под сеткой: SEO-текст категории (поле `description` уже есть)

### 4.3 Карточка товара (P0)
Порядок блоков (Goldberry + Pandora):
1. Крошки
2. Галерея (несколько фото, зум)
3. Название, артикул
4. Цена; старая цена, если есть скидка
5. **Выбор размера** со ссылкой «Как определить размер?»; недоступные размеры зачёркнуты
6. Наличие: «В наличии / Осталась 1 штука / Нет в наличии»
7. Кнопки: «В корзину» `[orders]` / «Оставить заявку» (режим без оплаты); «Уведомить о поступлении» (P1); «Уточнить в WhatsApp»; «Наличие в салонах» (P1)
8. Сворачиваемые блоки: **Характеристики** (металл, проба, цвет, вес, вставки с каратами), **Доставка**, **Оплата**, **Гарантия и возврат**
9. Описание
10. Похожие украшения
11. Структурированные данные Product (уже сделано)

### 4.4 Корзина и оформление (P0)
- Корзина: позиции, количество, итог, кнопка «Оформить»
- Оформление в **одну страницу**: контакты (имя, телефон, email), способ получения (самовывоз из салона / доставка), комментарий, согласие с офертой
- Режим **без оплаты**: кнопка «Оформить заявку», страница «Заявка принята, менеджер свяжется с вами»
- Режим **с оплатой** `[payments]`: «Оплатить» -> страница провайдера -> `/payment/return` проверяет статус на сервере
- Гость может оформить без регистрации; при `[accounts]` предзаполнение и сохранение адреса

### 4.5 Салоны (P0)
Карточка на каждый салон: город, адрес, телефон, часы работы, ссылка на карту. На странице салона (P1): фото, как добраться, какие услуги доступны.

### 4.6 Информационные страницы (P0)
Один шаблон: заголовок + текст. Контент сейчас в `ru.ts`, позже переносится в таблицу `pages`, чтобы клиент правил из админки.

### 4.7 Личный кабинет `[accounts]` (P1)
Профиль · Адреса · История заказов (со статусом и ссылкой) · Избранное. Структура как у Pandora (`/personal/...`).

## 5. Сервисные идеи из референсов (отдельно от MVP)

| Идея | Откуда | Приоритет | Комментарий |
|------|--------|-----------|-------------|
| Рассрочка (Kaspi, Halyk) | Goldberry, Pandora | решить с клиентом | Это не только баннер: влияет на оплату и юридические тексты. Вопрос ниже. |
| «Уведомить о поступлении» | Pandora | P1 | Особенно полезно при единичных изделиях |
| «Намекнуть на подарок» | Pandora | P2 | Форма отправляет письмо; хорошая вирусная механика |
| Подарочная упаковка | Pandora, Bulgari (предп.) | P1 | Платная или бесплатная опция при заказе |
| Подарочные карты | Goldberry | P2 | Требует учёта баланса, отдельная фича |
| Индивидуальное изготовление, ремонт, оценка | Goldberry | P1 | Пока можно сделать как статические страницы с кнопкой WhatsApp |
| Покупка в 1 клик | Goldberry | P2 | Упрощённая заявка по телефону |
| Отзывы | Goldberry | P2 | Модерация нужна |

## 6. Влияние на данные и работу (что поменять в проекте)

1. **Фильтр по цвету золота** (`gold_color` уже в модели и в seed): добавить в API (`gold_color=[...]`), фасеты и форму каталога. Малая правка, ценный фильтр.
2. **Подкатегории и подборки**: категории уже древовидные. Подборки («Для неё», «Свадьба») лучше сделать отдельной сущностью `collections` (many-to-many с товарами), а не категориями: один товар может входить в несколько. Добавить в P1.
3. **Хлебные крошки с JSON-LD `BreadcrumbList`** на категориях и товаре.
4. **Мега-меню** читает `GET /categories` (уже есть), фото-промо берёт из баннеров (`placement=menu_promo`).
5. **Страницы /warranty, /size-guide, /care, /faq**: контент через `pages`.
6. **Поиск**: `/search?q=` может быть просто страницей каталога с параметром `q` (уже работает на API).
7. **Несколько изображений на товар**: схема и пайплайн готовы, нужен только загрузчик в админке (день 8 плана).

## 7. Открытые вопросы к клиенту

1. Какие **услуги** действительно есть (изготовление на заказ, ремонт, оценка, подбор камней)? От этого зависит раздел `/services`.
2. **Рассрочка и кредит** (Kaspi/Halyk): планируется ли показывать? На каких условиях?
3. Нужны ли **подарочные карты** и **подарочная упаковка** (платная?).
4. **Доставка**: бесплатная от какой суммы, курьер по городу, по Казахстану (СДЭК, Kaspi Доставка, почта)?
5. **Гарантия и возврат**: готовый текст, сроки (у Goldberry возврат 14 дней с экспертизой палаты, у Pandora гарантия 6 месяцев).
6. Есть ли **готовые подборки/коллекции** и какие поводы важны (помолвка, свадьба, юбилей)?
7. Нужны ли **блог/новости** в MVP или позже?
8. Есть ли у украшений **цвет золота, вес, каратность вставок** в данных клиента (для фильтров и таблицы характеристик)?
9. Реальные **тексты и фото** для главной, «О нас», салонов.
10. Страница **Bulgari** недоступна из этого окружения. Если нужна именно она, пришлите скриншоты или текст меню и страницы категории, и я добавлю их в разбор.
